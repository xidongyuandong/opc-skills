# 从双技能版本迁移

对外只发布 `clash-verge-add-static-ip`，脚本、模板、校验器和回归已全部放在本目录；不需要联网下载另一个 skill。复制完整目录即可，不能只复制 SKILL.md。

若安装过旧版双技能：

1. 先备份两个目录和自己的自定义修改。真实订阅、参考凭据与生成 sidecar 应在 skill 目录外，不应随升级处理。
2. 安装新的完整 `clash-verge-add-static-ip`，运行安装探测测试和单目录隔离回归。
3. 检索自己脚本/快捷命令中的旧路径。将 `clash-verge-static-ip/scripts/` 更新为 `clash-verge-add-static-ip/scripts/`；同名 Ruby 构建器参数保持兼容。
4. 确认没有旧调用后，才按用户许可移除旧 skill 副本；安装过程不自动删除用户旧目录。需要过渡时可保留仅转发的新本机兼容入口，不再维护两套算法。

仓库后续提交移除旧技能发布目录，不代表任何已安装机器上的旧副本已被自动清理。旧双技能 ZIP 仅作历史回滚，不再作为新用户下载入口。

若迁移失败，从备份恢复两个目录并保留失败证据，不改真实 VPN 配置或强推仓库历史。
