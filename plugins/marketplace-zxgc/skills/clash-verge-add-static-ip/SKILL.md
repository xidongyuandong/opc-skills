# Clash Verge 新增静态 IP 订阅

完成用户旅程：安装检测/安装与复检 → 必要输入 → 识别原订阅 → 构建候选 → GUI 新增独立订阅 → 分层验收。
本 skill 自包含：构建器、模板、校验器和测试均随本目录提供，不需要安装另一个 skill。
先执行 [安装检测与安装流程](references/installation.md)，再进入 [构建与登记](references/operation.md)。

## 第一步：检测 Clash Verge 安装情况

使用本目录 `scripts/check_clash_verge_installation.py`（Python 3.9+，标准库）输出 JSON。
`installed` 表示找到安装文件证据，仍需核验应用身份、版本和能否打开；`not_found` 只表示常见位置未找到；`unknown` 表示权限、平台或路径证据不足。
先检测；不能判断时询问用户是否安装及自定义位置，不要直接索要一个不存在的订阅文件。
确认未安装后，按官方文档选择系统/架构对应的安装方式；普通本机安装在授权范围内执行，管理员授权或安装器交互由用户完成。安装后重新检测并确认应用可打开，再继续。
不执行任意发现的二进制以读取版本，不把残留配置目录、运行进程或内核 mihomo 当成 GUI 安装证明。

## 必要输入与缺项提示

先完成上述安装前置检查，再读取用户已提供的信息，只追问缺失项，尽量一次收齐：

1. **Clash Verge 配置文件绝对路径**。提示：“在 Clash Verge 软件 →【订阅】→ 右键原订阅 →【打开文件】，提供该文件的绝对路径。”必须存在且是可读配置文件，不从旧会话猜当前 UID。
2. **静态 IP 代理资料**：协议（如 SOCKS5 或 HTTP）、服务器地址、端口、认证方式及账号/密码（若需要）、购买地区、供应商提供的出口 IP（若有）。仅一个 IP 地址不足以建立代理；端口 443 不代表 HTTPS，不能自行猜协议或 TLS。
3. **原订阅显示名称**：优先从 GUI 或只读元数据获取，无法获取时请用户提供；不能使用随机 YAML 文件名作为显示名称。

没有购买时提示：“请先购买适用于代理接入的静态 IP，并提供协议、端口、认证与地区信息。你可以参考 https://share.cliproxy.com/share/6scsnkai1 或自行选择其他供应商。”这是需求提供的购买入口，不保证服务可用、价格、地区或质量，不代为购买。

凭据优先从用户提供的本机私有配置读取；不要要求把完整订阅 URL、密码或配置粘贴到公开渠道。凭据不进入命令行、日志、截图、打包产物或任务总结。私有候选和备份放在 skill 目录外，权限仅限当前用户。

可选项：用户有区域排除要求时收集名单；默认不照搬历史“排除港澳台”。询问仅限关键缺口：无法推断的协议/地区、多个入口规则需要不同覆盖、已存在静态链但目标不明。

## 分支与输出约定

- 可刷新的 **Remote**：通过 GUI 以原订阅 URL 新建独立 Remote 卡片；只给新卡片绑定专属扩展脚本。下载 YAML 是基础数据，扩展脚本是静态链真源。
- **Local**：在隔离目录合成独立 YAML，再通过 GUI 新建 Local。Local 不承诺能用“更新”刷新上游订阅。
- 新卡片名称为 `原订阅显示名称-地区`，如 `示例订阅-新加坡`。地区来自用户/供应商；不能按中转节点国家推断。重名时先检查是否本次已经创建，幂等复用已核实的本次条目；无关重名先询问或使用用户批准的新名称，不能覆盖。
- 保留原订阅、规则和当前选择。此次“新增静态 IP”不自动意味着全设备流量必须经静态 IP；保留 DIRECT 等业务规则并明确覆盖范围。若用户要求全部代理流量固定出口，先核对全部规则入口再适配，不能只改 MATCH 就声称实现。
- 当前用户已明确授权的本地构建、创建新订阅可连续完成，不对每一步重复要确认。切换当前出口、退出/重启或影响现有联网需看当前授权范围；仅要求创建新卡片时不自动切换。

## 不可跳过的验收

按 [操作流程](references/operation.md) 逐项记录：

1. **静态结构**：唯一静态代理 → dialer-proxy → 非空真实上游；无循环/重名/丢失引用；原规则保留；最终合成可被 Mihomo 接受。
2. **GUI 登记**：【订阅】能看见准确名称的新卡片；新 UID 唯一、类型正确、正式文件存在、原条目不变。文件生成或索引行存在不能代替 GUI 可见。
3. **出口生效**：授权切换后，核对实际入口选择静态出口，以及经该代理的公网 IP 和地区。两个检测源交叉验证；仅 HTTP 200 或国家一致不足以证明静态身份。
4. **更新保护**：Remote 普通更新和“更新（代理）”后，上游刷新、脚本仍有效、最终链路完整；原始下载内容不能与本次保留的代理/组名称碰撞。403/超时只能记该项未完成，不能偷偷降级 Local 后声称更新成功。

未授权/不可用的 GUI、切换或联网步骤明确列为未验证，并给出用户可执行的下一步。配置可解析不证明公网出口；一次 IP 命中不证明长期固定；未检查 TUN 不声称全设备覆盖。重启不是注册手段，只在明确需要并授权时验证。

完成时给出：新订阅名与类型、GUI 是否可见、覆盖范围、哪些层验证成立、尚缺项、受控产物路径和撤销方法。不要输出密码、完整订阅链接或含凭据代码。
